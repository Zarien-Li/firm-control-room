# Program Origin

## Sealed Arena

- Research arena: Replace with the broad research area.
- Canonical object: Replace with the object being improved or understood.
- Primary outcome: Replace with one decision-relevant outcome.
- Standard evidence surface: Replace with natural tasks, systems, or workloads.
- Baseline community: Replace with the incumbent methods that define fair comparison.

## Authority

The user owns changes to this program boundary. Session summaries and automated reviews are evidence,
not authority to silently narrow, pivot, freeze, or replace it.
